# Heimdall SOC

Security operations platform demo by [Svalbard Security](https://svalbard.ca/).

## Getting Started

Install dependencies

```bash
pnpm install
```

Start the server

```bash
pnpm run dev
```

Demo login: `peter.pan@svalbard.ca` / `demodemo123`

## Tech Stack

- shadcn/ui 4
- TailwindCSS v4
- Next.js 16
- React 19
- TypeScript
- Eslint v9
- Prettier
